# Skills Agent AI

This task demonstrates an autonomous tool-calling agent.

The agent:

1. Evaluates the user request.
2. Determines whether external information is required.
3. Selects an appropriate tool.
4. Executes the tool.
5. Evaluates the result.
6. Performs additional tool calls when required.
7. Synthesizes the final response.

The architecture follows the Plan → Act → Observe → Evaluate loop.
