# Task 02 - FastAPI Parameter Validation

## Objective

Build a FastAPI endpoint that demonstrates strict parameter validation using Python type annotations and Pydantic validation rules.

The endpoint accepts a required user identifier and an optional filtering tag.

## Technologies Used

- Python 3.13
- FastAPI 0.128.0
- Uvicorn 0.40.0
- Pydantic
